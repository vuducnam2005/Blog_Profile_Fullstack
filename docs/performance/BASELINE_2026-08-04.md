## 8. Cache và compression baseline

- Vercel đang trả Brotli cho HTML, JavaScript và CSS.
- HTML trả `Cache-Control: public, max-age=0, must-revalidate`.
- Asset có hash cũng đang trả `Cache-Control: public, max-age=0, must-revalidate`.
- `avatar_AI.webm` không có hash và cũng dùng `max-age=0, must-revalidate`.
- Vercel Edge trả `X-Vercel-Cache: HIT` trong mẫu kiểm tra.
- Cloudinary original media có cache dài hạn, nhưng ảnh đang tải ở kích thước gốc.
